PhishCheck

Paste a link. Get a risk score and a plain-English report.

Team prototype. The final project is a C++ console app with the same rules and report. The tool never opens the link; it only reads the text of the URL, so it estimates risk and can’t prove a site is malicious.

Paste a link above or try a sample. Every check is saved to History so you can search and sort it later.
